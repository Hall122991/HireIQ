# HireIQ Agent ⚡

AI-powered recruiting platform built with React + Claude AI.

## Features

- 📄 Resume Analyzer — instant AI scoring and extraction
- 📦 Bulk Upload — analyze up to 100 resumes at once
- ⭐ AI Candidate Ranking — ranked top 10 with tier badges and actions
- 🎯 JD Matcher — match candidates to job descriptions
- 🔁 Auto Follow-Ups — multi-touch sequences across Email, SMS, LinkedIn
- 📋 Hiring Reports — full pipeline analytics with source performance
- ✍️ JD Writer — generate compelling job descriptions
- 📧 Outreach Emails — 3-touch cold email sequences
- 🔍 Screening Automation — interview frameworks and scorecards
- 🔗 ATS Sync — Greenhouse, Lever, Ashby and more
- 👥 Team Collaboration — shared candidate review and comments
- 📊 Analytics — hire quality vs AI score correlation

## Setup

```bash
npm install
npm run dev
```

## Deploy

Drop `hireiq.html` on [netlify.com/drop](https://netlify.com/drop) for instant deployment.

Or deploy to Vercel:
```bash
vercel deploy
```

## Tech Stack

- React 18 + Vite
- Recharts for analytics
- Claude claude-sonnet-4-20250514 (Anthropic API)
